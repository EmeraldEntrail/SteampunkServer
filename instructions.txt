===================================================================
                PACKWIZ AUTO-UPDATE CHEAT SHEET
===================================================================

STEP 1: ADD YOUR NEW MOD(S)
---------------------------
Open PowerShell inside this folder and run ONE of these commands:

  For Modrinth Mods:
  .\packwiz modrinth install [PASTE_MOD_URL_HERE]

  For CurseForge Mods:
  .\packwiz curseforge install [PASTE_MOD_URL_HERE]


STEP 2: BROADCAST THE UPDATE TO YOUR FRIENDS
--------------------------------------------
Copy and paste this entire 1-line block into your PowerShell window 
and hit Enter. It will automatically convert the quote layout, 
refresh your tracking hashes, and force-push the clean update live:

Get-ChildItem mods\*.pw.toml, mods\.index\*.pw.toml -ErrorAction Ignore | ForEach-Object { (Get-Content $_.FullName) | ForEach-Object { $_ -replace '"', "'" } | Set-Content $_.FullName } ; .\packwiz refresh ; git add . ; git commit -m "Pack Update" ; git push --force


===================================================================
DONE! Wait for the GitHub Actions circle to turn green, then your 
friends' launchers will automatically download the updates!
